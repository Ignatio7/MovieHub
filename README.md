# 🎬 MovieHub

REST API-сервис для управления коллекцией фильмов, написанный на чистой Java без фреймворков.

## О проекте

MovieHub — это учебный backend-проект, реализующий полноценный HTTP-сервер с CRUD-операциями над коллекцией фильмов. Проект написан в рамках курса **«Java-разработчик»** от Яндекс Практикума.

Основная цель — отработать навыки построения REST API, работы с HTTP-протоколом, валидации данных и сериализации JSON без использования фреймворков Spring.

## Функциональность

| Метод | Эндпоинт | Описание |
|-------|----------|----------|
| `GET` | `/movies` | Получить все фильмы (с фильтрацией по году: `?year=2024`) |
| `GET` | `/movies/{id}` | Получить фильм по ID |
| `POST` | `/movies` | Добавить новый фильм |
| `DELETE` | `/movies/{id}` | Удалить фильм по ID |

### Валидация при создании фильма
- Название: не пустое, не длиннее 100 символов
- Год выпуска: от 1888 до текущего года + 1

### HTTP-статусы
- `200` — успешный запрос
- `201` — фильм создан
- `204` — фильм удалён
- `400` — некорректные параметры
- `404` — фильм не найден
- `415` — неподдерживаемый тип контента
- `422` — ошибка валидации данных

## Технологический стек

- **Java** — основной язык
- **com.sun.net.httpserver** — встроенный HTTP-сервер JDK
- **Gson 2.10.1** — сериализация/десериализация JSON
- **Maven** — сборка и управление зависимостями

## Структура проекта

```
src/main/java/ru/yandex/practicum/moviehub/
├── Movie.java            # Модель данных фильма (id, title, year)
├── MoviesStore.java      # Хранилище фильмов (in-memory)
├── MoviesHandler.java    # Обработчик HTTP-запросов
├── BaseHttpHandler.java  # Базовый класс обработчика
├── ErrorResponse.java    # Модель ошибки в JSON-ответе
└── MoviesServer.java     # HTTP-сервер (порт 8080)
```

## Запуск

**Требования:** Java 11+, Maven 3.6+

```bash
git clone https://github.com/Ignatio7/MovieHub.git
cd MovieHub
mvn compile
mvn exec:java -Dexec.mainClass="ru.yandex.practicum.moviehub.MoviesServer"
```

Сервер запустится на `http://localhost:8080`.

## Примеры запросов

```bash
# Получить все фильмы
curl http://localhost:8080/movies

# Добавить фильм
curl -X POST http://localhost:8080/movies \
  -H "Content-Type: application/json" \
  -d '{"title": "Inception", "year": 2010}'

# Получить фильм по ID
curl http://localhost:8080/movies/1

# Фильмы за конкретный год
curl http://localhost:8080/movies?year=2010

# Удалить фильм
curl -X DELETE http://localhost:8080/movies/1
```
